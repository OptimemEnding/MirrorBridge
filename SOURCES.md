# Project resources

MirrorBridge's custom application resources are stored under `assets/` and
`android/app/src/main/assets/`.

Built-in Cube LUT presets are generated by `scripts/generate_luts.py`.
Watermark previews are generated by `scripts/generate_visual_assets.py`.

`assets/SOURCE_MANIFEST.json` stores hashes for project-managed release assets,
and `scripts/verify_sources.py` checks that generated resources are up to date.

Third-party dependency notices are collected in `THIRD_PARTY_LICENSES.txt` and
`THIRD_PARTY_NOTICES.md`.
